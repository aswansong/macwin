# v1.0.1 macOS `.habitpack` 原生闭环修复记录

状态：`fix/v1.0.1-macos-habitpack-e2e`，仅供知情测试；未合并 `main`、未修改 `release/v1.0.1`、未创建 Release。

## 根因

真实迁移包可以通过 Rust 严格解析并进入强制计划页，但前端手写 `invoke` payload 与 Tauri v2 命令边界不一致：

- `confirm_plan` 的 Rust 参数名是 `confirmation`，前端却把 `selected_module_ids` 等字段放在了顶层。
- `apply_plan` 的顶层 primitive 参数由 Tauri v2 暴露为 camelCase，前端传 snake_case。
- `rollback_module` 的顶层参数同样需要 `moduleId`。
- 错误处理把错误消息中的第一个大写词当作错误码，导致 Tauri 的 `INVALID` 被误记为稳定诊断。

## 修复设计

- 新增 `src/native-bridge.ts`，集中定义命令、参数 envelope、返回类型和安全错误码解析；视图不再直接调用 `invoke`。
- `confirm_plan` 使用 `{ confirmation: { selected_module_ids, keyboard_built_in, keyboard_external } }`。
- `apply_plan` 使用 `{ keyboardBuiltIn, keyboardExternal, selectedModuleIds, confirmationToken }`；回滚使用 `{ moduleId }`。
- 原生错误只记录稳定代码；Tauri 缺少参数统一为 `TAURI_INVALID_ARGS`，界面提供中文解释，不记录路径、包内容或原始错误文本。
- `confirm_plan` 拒绝空选择；Rust DTO 与前端 envelope 均有回归测试。

## 真实走查

使用用户提供的外部迁移包完成两次本地 Apple 芯片 Mac 走查：

1. 导入 → 严格解析 → 强制计划 → 确认 → 创建快照 → 应用并验证 Finder、键盘重复速度、选择性 Ctrl 与原生滚动方向。
2. 查看本地报告；按模块恢复一个设置；再次执行全部恢复并验证。

软件结果保持 `manual_action_required`，没有静默下载或安装；没有触发第三方安装、管理员权限或辅助功能授权门槛。
