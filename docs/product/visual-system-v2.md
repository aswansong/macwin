# MacWin 完整可点击视觉系统 v2

状态：`prototype/visual-system-v2` 分支内的视觉实现说明；不是品牌资产或正式发布承诺。[D-021、D-028、OD-004]

## 这轮解决的问题

把已接受的精简流程变成一套可以在浏览器预览中完整点击的界面：Windows 采用 `W1 → W2 → W3`，Mac 采用 `B 封面 → C 迁移地图`。浏览器预览只使用代码内的虚构数据和 preview bridge，不读取或修改真实系统，也不把生成参考图当作生产切图。[D-028、E-017]

## 已采用的页面结论

| 页面 | 视觉结论 | 主要动作 |
| --- | --- | --- |
| W1 简洁首页 | 先显示这台 Windows、四类范围和支持状态；一个主按钮 | 开始检测 |
| W2 通行证互动 | 左侧连续选择列表，右侧 CSS/HTML `.habitpack` 票面实时增删模块；软件只展示检测结果，在 Mac 计划中确认一次 | 选择习惯、指南和 Wi‑Fi 密码 |
| W3 路线式导出 | 检测、选择、导出三段路线；生成前先复核，生成后显示验证和本地交接提醒 | 生成并验证、交给 Mac |
| B 通行证封面 | Mac 首屏是通行证品牌对象和导入入口；不把封面标题复用到流程页 | 导入 `.habitpack` |
| C 迁移地图 | 左侧路线承载导入、计划、执行、结果；右侧连续模块列表，敏感、权限、第三方和恢复信息首层可见 | 确认计划、执行、查看结果/报告/指南/恢复 |

## 视觉 Token（本轮分支方案）

- 纸张：`#FAFBF8`；白色信息层：`#FFFFFF`；墨蓝文字：`#20324B`。
- 晴蓝：`#4F83F1`，用于 Windows 路线、主要选择和可聚焦动作。
- 珊瑚：`#EC7868`，用于 Mac 入口、敏感提示和需要再次确认的动作。
- 薄荷：`#77C5A8`，用于已验证、可恢复和安全边界提示。
- 黄色：`#F3C95B`，只用于待处理、权限拒绝和需要注意的结果。
- 中文使用系统 UI 字体栈，短标签使用系统等宽字体；不加载外部字体、图片或 CDN。
- 圆角主要使用 8–18px；阴影只用于票面和 W1 主动作，避免全屏漂浮层。

## 组件与状态表达

- `journey`：Windows 三阶段路线，或 Mac `map-rail` 四阶段迁移地图；当前步骤同时用编号、文字和颜色表达。
- `passport-card`：用票面、穿孔边缘、模块章和本地/敏感印章构成品牌对象；没有飞机、机场或旅游口号。
- `selection-row` / `map-module-row`：连续列表优先于密集卡片墙；复选框本身表达选择，不重复写“已选择”。
- `risk-badge`：`需要授权`、`含敏感信息`、`需手动完成`、`需单独确认`、`可恢复` 在不展开说明时可见。
- `activity-panel`：显示快照、执行、验证的阶段性结果，不用单一旋转动画代替模块状态。
- `result-row`：状态同时使用图形、文字和结果句；权限跳过、手动完成、失败可恢复和未知状态不显示为成功。
- 预览开发条只在 Vite 开发预览显示，可切换 `platform` 与 `scenario`，用于复现正常、UAC 拒绝、Mac 权限拒绝、离线、第三方拒绝、单模块失败和损坏包；它不进入生产构建界面。

## 明确禁止项

- 不使用全屏渐变、霓虹赛博、深色荧光 AI 风格、重毛玻璃、发光球体或数据仪表盘。
- 不使用营销口号、统计噪声、重复“已选择/未选择”标签或无意义的“查看排除原因”。
- 不把生成图直接嵌入 UI；参考图只用于方向校准，页面由 HTML/CSS/TypeScript 和必要的轻量图形实现。
- 不隐藏 Wi‑Fi 密码不加密、管理员/UAC、Mac 权限、第三方工具、常驻影响、不可自动恢复和恢复边界。
- 不把部分失败、权限拒绝、离线待处理或第三方未确认显示成全部成功。
- 不新增遥测、账号、后端、外部字体、外部图片或运行时 CDN。
