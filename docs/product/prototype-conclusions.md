# M1 可点击原型结论（可丢弃交互验证）

状态：M1 原型结论；不是生产实现、真实设备验证或新的产品决定。

原型分支：`prototype/ui-flow-v1`。入口：`index.html`；代码：`prototype-ui-flow/`。所有数据和结果均为虚构，状态只保存在浏览器内存。

## 原型回答的问题

本原型验证 Windows → `.habitpack` → Mac 的信息层级是否能让用户在任何模拟更改前理解计划、权限、第三方候选、失败隔离与恢复入口。它还比较两项局部方案：问卷可在“宽松 / 紧凑”密度间切换，计划可以“折叠 / 展开”阅读。两项方案都使用同一份流程和虚构数据，并不是多套产品。

## 已验证的交互假设

- 强制计划确认位于 Mac 导入检查之后、模拟快照之前；状态机与测试都拒绝从导入或计划直接进入模拟执行。[D-010]
- 风险可以在折叠计划和问卷项中保持可见：`含敏感信息`、`需管理员`、`安装第三方工具`、`不可自动恢复` 均以文字标签呈现，不依赖颜色。[D-011、D-019、D-021]
- 约 5 道纯选择题可以同时保留已决定的预选项（内置/检测到的外接 Windows 键盘、指南）和明确未预选的敏感项（密码/管理员权限）。[D-006、D-007、D-019]
- 集中说明权限后，拒绝只影响键盘模块；离线、第三方拒绝和模块失败在完成报告中都不会被汇总成“迁移完成”。[D-014、D-026]
- 结果、指南、主页和恢复可以从同一模块状态派生；恢复清楚写为“迁移前状态”，不称为恢复出厂设置。[D-012、D-015]

## 尚未验证或被否定的假设

- 未验证真实平台接口、UAC/TCC 行为、ZIP 解析、快照、软件安装、网络写入、第三方供应链或任何真实用户可观察系统结果；这些属于 M2/生产阶段，不应从本原型推断为可行。[D-022、D-023]
- 未验证“宽松/紧凑问卷”和“折叠/展开计划”哪一种更适合新手；原型仅提供可切换的可用性测试材料。推荐先以宽松问卷和折叠计划为测试默认，因为风险标识持续可见、页面负担较低；是否采纳仍需用户测试，不是新决定。
- 没有证据显示未加密 `.habitpack` 中的真实 Wi‑Fi 凭据可安全处理；原型只展示不回显的风险提示。OD-005 继续阻断真实凭据实现。[D-019]

## 安全与范围声明

原型没有读取或修改 Windows/macOS 设置、注册表、Wi‑Fi 密码、真实软件或个人数据；没有 UAC、TCC、Karabiner-Elements、LinearMouse、Homebrew 或其他安装；没有外部网络请求、外部 API、账户、后端、数据库、原生桥接、Shell、PowerShell、自动更新、安装包或 Release。它不会生成或导入真实 `.habitpack`。

M1 完成后应停止在该分支，由负责人决定哪些结论进入下一阶段。[D-024]
