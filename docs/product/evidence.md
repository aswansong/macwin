# 证据目录

本文件把产品结论追溯到此前项目对话中的真实问题、实验与访谈。它是摘要索引，不是逐字聊天记录；为避免泄露隐私，不收录真实用户名、设备标识、本地路径、账号、密码、plist 或注册表内容。

## 证据分级

- **已观察**：在真实设备或既有操作中出现过，可作为设计输入，但不等于已由 MacWin 自动化验证。
- **用户陈述**：负责人明确描述的目标、偏好或痛点。
- **访谈结论**：在需求澄清中明确同意的产品选择；正式约束仍以 `D-xxx` 决策为准。
- **待验证假设**：目前合理，但必须通过原型、技术预研或真实设备测试验证。

## 证据条目

### E-001：Ctrl 与 Command 是首要肌肉记忆冲突

- 类型：用户陈述、已观察
- 摘要：长期 Windows 用户习惯 `Ctrl+C/V/X/Z/A/S/F`，初次使用 Mac 时会频繁误按；直接把所有 Ctrl 与 Command 全局交换又可能破坏终端、远程桌面和虚拟机中的真实 Ctrl。
- 产品含义：需要“选择性 Ctrl 兼容”，并保留 Command 和真实 Ctrl 场景，而不是做全局交换。
- 关联决定：D-004、D-007

### E-002：已有键盘规则实验说明“按设备、按应用”可行但复杂

- 类型：已观察
- 摘要：此前曾用约 41 条 Karabiner 规则尝试区分 MacBook 内置键盘、外接 Windows 键盘和应用例外。实验暴露出规则冲突、例外遗漏和故障排查难度。
- 产品含义：第一版必须使用声明式白名单、显式例外和可回滚模块；不能把任意规则脚本塞进迁移包。
- 关联决定：D-007、D-011、D-027

### E-003：鼠标与触控板需要分别配置

- 类型：已观察
- 摘要：Windows 用户常希望鼠标滚轮保持传统方向，同时保留 Mac 触控板的自然滚动；设备连接、断开或重新识别可能改变实际效果。
- 产品含义：鼠标和触控板是两个独立计划项，执行后必须分别验证。
- 关联决定：D-005、D-012

### E-004：DMG、应用安装与磁盘映像弹出不符合 Windows 心智

- 类型：已观察
- 摘要：Windows 用户容易把 DMG 当成安装后仍需保留的程序，或不理解把 App 拖入“应用程序”及弹出磁盘映像的含义。
- 产品含义：软件安装流程和迁移后指南必须解释 Mac 安装模型，自动安装也要报告来源与结果。
- 关联决定：D-013、D-015

### E-005：关闭窗口不等于退出应用

- 类型：已观察
- 摘要：红色关闭按钮、`Command+Q`、Dock 指示点、全屏与桌面空间等行为，与 Windows 的窗口/进程心智不同。
- 产品含义：个性化指南应解释高频差异；MacWin 不应为了模仿 Windows 而全面改写 Mac 原生窗口模型。
- 关联决定：D-004、D-015

### E-006：macOS 隐私权限必须由系统逐项授权

- 类型：已观察
- 摘要：辅助功能、输入监控、文件访问等权限受到 macOS TCC 约束，不能由普通应用静默代替用户批准；拒绝权限不应阻断无关模块。
- 产品含义：采用集中引导、系统逐项授权、拒绝后降级继续的流程。
- 关联决定：D-014、D-027

### E-007：轻量 AI 编程环境是核心使用场景之一

- 类型：用户陈述、已观察
- 摘要：目标设备主要用于 AI 编程、文档、表格、Codex/Claude Code 类对话和外出轻量工作；Git、编辑器、Python、Node 等环境配置是显著迁移成本。
- 产品含义：提供可选的轻量开发环境模块，但不强迫普通用户安装开发工具。
- 关联决定：D-005、D-020

### E-008：页面缩放与系统屏幕缩放容易混淆

- 类型：已观察
- 摘要：Windows 用户可能把浏览器页面缩放、系统显示缩放和辅助功能缩放混为一谈。
- 产品含义：浏览器模块只处理浏览器选择、安装和安全偏好；指南解释差异，不迁移浏览数据。
- 关联决定：D-015、D-018

### E-009：续航与电源管理是迁移动机，也是心智差异

- 类型：用户陈述、已观察
- 摘要：便携与长续航是选择 MacBook 的主要原因之一；合盖、睡眠、低电量模式和后台活动与 Windows 体验不同。
- 产品含义：指南解释 macOS 电源行为，但第一版不承诺通过激进系统修改提升续航。
- 关联决定：D-004、D-015

### E-010：通知、角标和专注模式需要解释而非盲目复制

- 类型：已观察
- 摘要：通知授权、Dock 角标和专注模式在两个平台上的控制入口及行为不同。
- 产品含义：仅迁移白名单内可安全表达的偏好，其他差异进入指南。
- 关联决定：D-004、D-009、D-015

### E-011：音频输入输出会随设备改变

- 类型：已观察
- 摘要：蓝牙耳机、显示器和外接设备可能改变默认输入输出；简单复制一个设备名无法保证目标 Mac 存在相同设备。
- 产品含义：第一版不承诺迁移硬件绑定的音频设备，最多提供检测结果和使用指南。
- 关联决定：D-002、D-009

### E-012：打印队列成功不等于真实打印成功

- 类型：已观察
- 摘要：此前排查打印问题时，系统队列完成并不能证明纸张输出成功；网络、协议、驱动和打印机自身状态都可能造成假成功，AirPrint 路径曾需要纠正并在设备侧复核。
- 产品含义：第一版不迁移打印机；未来任何硬件迁移验收都不能只看命令返回值。
- 关联决定：D-002、D-023

### E-013：部分服务策略不是本机设置

- 类型：已观察
- 摘要：例如微信等服务的账号、风控或服务端策略不能靠本机配置迁移解决。
- 产品含义：账号状态、登录会话和服务端行为属于明确非目标，不得包装成可迁移功能。
- 关联决定：D-002、D-018

### E-014：网络和外设环境会漂移

- 摘要：Wi‑Fi、打印机、蓝牙和路由器环境会在扫描后、导入前或执行后发生变化。
- 产品含义：计划必须显示匹配依据；执行前后重新检查依赖；失败要按模块隔离。
- 关联决定：D-010、D-012、D-019

### E-022：M2 Wave 0 v1 安全研究进展

- 类型：技术研究、官方文档核对
- 摘要：Windows `WlanGetProfile` 的明文 key 读取需要显式的 plaintext-key 标志和受保护的 WLAN 读取权限；默认通常只允许管理员。Apple `NEHotspotConfiguration` 能配置 WPA/WPA2 Personal 的 SSID/口令，但需要相应网络能力与 entitlement；它不是“读取旧密码”的接口。LinearMouse 官方说明确认其需要 Accessibility 权限，并且是独立的常驻鼠标/触控板工具。
- 产品含义：Wi‑Fi 密码链路必须继续停在 OD-005 决策门，不能用命令行回显、剪贴板或未验证的跨平台配置文件冒充安全实现；鼠标/触控板独立方向在原生接口不足时必须明确降级并要求官方工具授权。当前实现已采用这两个安全降级原则。
- 参考： [Microsoft WlanGetProfile](https://learn.microsoft.com/en-us/windows/win32/api/wlanapi/nf-wlanapi-wlangetprofile)、[Apple NEHotspotConfiguration](https://developer.apple.com/documentation/networkextension/nehotspotconfiguration)、[LinearMouse 辅助功能说明](https://github.com/linearmouse/linearmouse/blob/main/ACCESSIBILITY.md)
- 关联决定：D-019、D-032、OD-005、OD-007
