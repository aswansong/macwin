# MacWin 计划页 v4 内容精简记录

## 本次调整

- 顶部品牌副标题改为“双持 Mac 和 Windows 的好帮手”。
- Windows 与 Mac 计划不再展示“键盘重复速度”；旧迁移包中的该模块仍被安全过滤，不会进入 v4 的确认和执行选择。
- Mac 计划页首屏只显示“系统与习惯”和“软件与开发”两行，各自一个总选择框；Wi‑Fi 仍作为系统组内的独立可选项，不会因为密码未选而让总组显示半选。
- 展开分组后只显示简短选项名和一行用途，不再显示“查看动作说明”“查看边界”、安装策略或结果字段。
- 点击具体选项名称打开详情弹窗，解释会做什么、会看到什么结果和如何恢复；鼠标选项在弹窗内保留 LinearMouse 的授权确认与官方入口。

## 验证

- 浏览器验证 Mac 计划折叠/展开、两组全选与取消、Ctrl 详情、鼠标权限详情、软件详情、取消计划和正常应用。
- 验证 390×844、1280×720 无横向溢出，Windows W2 不再出现键盘重复速度文案。
- 原有 Tauri 命令、权限边界、快照/恢复和迁移包结构未修改；本分支仍是虚构数据原型。
