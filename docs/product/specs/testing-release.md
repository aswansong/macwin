# 测试与发布规格

## 1. 发布阶段

### R0：文档基线（已完成）

交付产品简报、证据、决策、规格、功能清单、执行计划和仓库规则。没有应用代码、安装包或产品测试，不得发布功能演示。[D-024]

### R1：可丢弃交互原型与格式规范（已完成）

交互原型已冻结在 `prototype/ui-flow-v2-hardening` 的提交 `37edc4edd52f2d0fb5aa7d796faa5fd7437bbb75` 并获接受；`main` 中的 `.habitpack` M1 格式规范和虚构夹具也已闭合，M1 已停止。原型使用虚构数据，不扫描、不提权、不联网、不修改系统，也不直接合入正式实现；M2 Wave 0 仅获局部研究授权。[D-024、D-028、D-029、E-018]

### R2：技术预研（Wave 0 局部已授权；真实平台其余部分未授权）

Wave 0 只允许以下四个隔离研究流：M1 `.habitpack` `1.0.0` 独立 parser；一次性 Tauri 2 最小壳与 mock bridge；synthetic snapshot/恢复；离线签名与 fictional supply-chain fixture。研究代码只能在 `codex/m2-*` 分支，不能创建 PR、合并 `main` 或 Release；只使用虚构数据和锁定开发验证依赖。真实平台的 Windows 白名单读取、macOS 设置适配、权限、Wi‑Fi、生产快照、第三方实际供应链和更新签名仍未授权。[D-022、D-029、E-018、OD-005、OD-006、OD-007]

### R3：知情 Alpha（未授权）

允许未签名构建，但只分发给明确知道风险、愿意使用测试设备/可恢复环境并按测试协议反馈的人。[D-023]

### R4：公开新手版本（未授权）

必须满足本文件的发布门槛、签名公证和真实设备矩阵，不要求新手绕过系统安全警告。[D-023]

## 2. P0 测试层级

### 2.1 文档/Schema 测试

M1 仓库统一入口为 `./scripts/validate-m1`；它只验证格式与虚构夹具，不替代下述生产测试。

- 严格解析 `feature-list.json`；
- 检查所有 P0 都有依赖字段、非空风险、决定引用和可观察验收；显式声明的依赖图根功能可以使用空依赖；
- 检查所有 `D-xxx`、`OD-xxx`、`E-xxx` 引用存在；
- 检查 Markdown 相对链接；
- 校验 `.habitpack` 与规则 JSON schema 的有效/无效夹具。

### 2.2 单元与属性测试

- 输入值到声明式计划的映射；
- 支持矩阵和版本比较；
- 路径规范化、大小限制、重复键/路径和 Unicode 碰撞；
- M1 ZIP 的连续布局、零 comment/extra/flags、Stored/Deflate 方法、固定版本/时间/属性与 UTF-8 字节顺序，以及 ZIP64、保留位和未知压缩拒绝；不同 Deflate level 都必须保持有效；
- Stored/Deflate 声明范围的唯一完整消费、流后数据/第二流/填充拒绝，以及 ZIP64 size sentinel 的稳定优先级；
- JSON 非有限数（包括正/负指数转换溢出）、BOM/非 UTF-8、解码后 surrogate code unit（对象键、字符串值、surrogate escape pair）、字符串/转义感知的嵌套深度和整数字面量边界，以及 canonical UTC `created_at` 的小写、offset、leap second、小数秒、仅日期与非法日期负例；literal UTF-8 emoji/中文和有限指数、浮点负零的策略也必须稳定；ZIP local/central 非法 UTF-8 文件名和 `zipfile` 解码异常也必须稳定拒绝；
- 日志脱敏和秘密检测；
- 模块依赖排序、失败隔离和状态汇总；
- 快照/恢复的幂等性与中断恢复。

### 2.3 集成测试

- Windows 普通扫描不会请求 UAC；
- 用户选择 Wi‑Fi 密码时的单次特权读取及拒绝降级；
- 生成包后由独立读取器往返校验；
- Mac 导入在计划确认前零系统变化；
- 快照失败阻断执行；
- 权限拒绝只跳过依赖动作；
- 一个模块失败不阻断独立模块；
- 第三方下载校验失败时不安装；
- 断网时本地模块完成，网络模块标记可重试；
- 删除/重装后发现快照并恢复。

### 2.4 安全测试

- ZIP 路径穿越、符号链接、压缩炸弹、重复/碰撞路径和未知文件；
- 未知规则、类型混淆、参数边界和命令/路径注入；
- 更新/规则/第三方签名错误、过期、回滚和撤销；
- 日志、报告、错误、崩溃信息和快照中的秘密扫描；
- 特权边界调用者和固定参数验证；
- 中断、断电或进程崩溃后的快照与系统一致性。

### 2.5 可用性测试

至少由从未长期使用 macOS 的 Windows 用户完成：

- 不打开终端走完主流程；
- 在计划确认前指出会改哪些模块；
- 识别 Wi‑Fi 包不加密、第三方安装和管理员权限；
- 执行后找到报告、指南和一个模块恢复入口；
- 解释普通应用使用兼容 Ctrl、终端保留真实 Ctrl；
- 面对一个权限拒绝和一个模块失败，知道下一步是重试、跳过还是恢复。

任务完成与是否理解分别记录，不能用访谈者提示后的成功替代独立完成。

## 3. 真实设备矩阵

正式宣称第一版支持前至少覆盖：[D-017、D-023]

| 角色 | 最低矩阵 | 必测项 |
|---|---|---|
| 来源端 | 一台 Windows 10 x64、一台 Windows 11 x64 | 普通扫描、UAC 允许/拒绝、导出、无网 |
| 目标端 | Apple 芯片 Mac + macOS 15；Apple 芯片 Mac + macOS 26 | 导入、权限允许/拒绝、执行、重启/睡眠、恢复、重装发现备份 |
| 键盘 | MacBook 内置键盘、一把外接 Windows 布局键盘 | 普通应用与真实 Ctrl 例外、重连 |
| 指针 | 内置触控板、一只外接鼠标 | 独立滚动方向、重连、第三方拒绝 |
| 网络 | 允许的个人 WPA2/WPA3 测试网络 | 密码允许/拒绝、无网、失败清理、报告无秘密 |

如果同一台设备通过独立系统环境覆盖版本，报告必须写清方法和未覆盖的硬件差异；不能把模拟器/虚拟机结果冒充全部真实硬件验证。

## 4. 关键场景验收

### 键盘

- 普通应用中的每个白名单 Ctrl 动作产生预期结果；
- 同一动作的 Command 原生组合仍有效；
- Terminal、VS Code 终端、远程桌面和虚拟机中的 Ctrl 序列未被转换；
- 关闭模块并恢复后，规则不再生效。[D-007]

### 指针

- 触控板和鼠标方向分别与计划一致；
- 修改/恢复一个不会改变另一个；
- 设备断开重连后重新验证，无法验证则显示未知或需重试。[E-003、D-026]

### Wi‑Fi

- 只列出允许的个人网络并逐项选择；
- 未选密码时包中无 credential，`contains_secrets=false`；
- 选密码时 `contains_secrets=true`，但秘密扫描在 UI、日志、报告、错误和快照中零命中；
- UAC 拒绝后仍可导出名称并显示降级；
- Mac 端失败后临时明文清理测试通过；
- 企业/证书/受管网络被拒绝。[D-019]

### 软件与开发环境

- 每个自动安装项来自白名单来源并验证版本；
- 无网或校验失败时不安装，状态不是成功；
- 普通路径不安装 Homebrew 或开发工具；
- 用户选择开发模块时先解释 Homebrew，再要求独立确认；
- 不读取或迁移 Token、SSH 密钥和项目文件。[D-013、D-020]

### 恢复

- 没有有效快照时执行按钮不可用；
- 每个可恢复模块能回到实际迁移前值并被读取验证；
- 全部恢复按依赖逆序且不影响未参与迁移的设置；
- 删除并重装应用后仍可发现备份；
- Wi‑Fi 快照不含密码。[D-012、D-019]

## 5. Alpha 进入标准

进入知情 Alpha 前必须：

- 所有 `P0-*` 功能至少达到 `implemented`，对应自动化检查通过；
- OD-005、OD-006、OD-007 中与 Alpha 实际启用功能相关的部分已关闭或明确禁用该功能；
- 完成威胁模型评审且无未处理的高危问题；
- 使用虚构数据完成端到端演练和恢复演练；
- 安装包清楚显示未签名/测试性质，不诱导绕过安全策略；
- 测试者知情同意文本、反馈范围和数据清理步骤已准备。[D-023]

## 6. 公开新手版本阻断门槛

以下全部满足才可发布：[D-023]

- 所有 P0 验收项状态为 `verified` 并有可复查证据；
- 真实设备矩阵通过，无阻断级缺陷；
- macOS 应用已签名并公证，Windows 安装包已可信签名；
- GitHub Release 的二进制、哈希、源代码标签和变更说明一致；
- 新手不需要终端或绕过 Gatekeeper/SmartScreen；
- 第三方来源、许可证和完整性验证通过；
- Wi‑Fi 秘密生命周期及秘密扫描通过；
- 模块恢复与重装发现备份演练通过；
- README、隐私说明、已知限制和卸载/恢复说明与实际功能一致；
- GitHub 安全报告入口和公开支持入口有效。[D-015、OD-001]

- 原型流程可点击，但没有真实系统实现；
- “大多数时候没问题”“看起来正常”或其他不可复现描述。[E-012、D-023、D-026]
