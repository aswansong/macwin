# 核心流程规格

## 1. 端到端边界

MacWin 由 Windows 来源端和 macOS 目标端组成。两端通过用户自行传输的 `.habitpack` 协作；MacWin 不提供云同步、账号或个人文件传输。[D-002、D-003、D-008]

核心状态：

```text
not_started
  → compatibility_checked
  → scanned
  → selections_confirmed
  → package_exported
  → package_imported
  → plan_confirmed
  → snapshot_created
  → applying
  → verified
  → completed | completed_with_actions | failed_recoverable
  → partially_rolled_back | fully_rolled_back（用户主动恢复时）
```

状态只表示流程阶段；模块结果必须单独记录，不能用一个全局“成功”掩盖部分失败。[D-026]

## 2. Windows 来源端

### 2.1 欢迎与兼容性检查

必须显示：

- 当前产品是 Windows → Mac，且不搬个人文件；[D-002]
- 扫描和导出在本机完成，不上传；[D-008]
- `.habitpack` 第一版不加密；若选择 Wi‑Fi 密码，任何拿到文件的人都可能读取其中秘密；[D-009、D-019]
- 当前系统、架构、MacWin 版本和规则版本是否受支持。[D-016、D-017]

不支持的平台默认不得进入扫描。实验性平台只有在未来负责人明确启用时才能继续；当前文档没有启用任何实验性平台。[D-017]

### 2.2 白名单扫描

普通扫描不得触发 UAC。扫描器只读取与已知规则相关的字段，并在后端为每个发现项保留规则 ID、类别、来源类型、可迁移状态、需要权限、检测置信度和排除原因；首层界面无需展示统计或排除原因入口。[D-006、D-009、D-014、D-028]

扫描器不得：

- 遍历或打包用户个人文件；
- 完整导出注册表；
- 读取浏览器密码、历史、Cookie 或会话；
- 执行远程脚本；
- 在普通扫描阶段读取 Wi‑Fi 明文密码。[D-002、D-009、D-018、D-019、D-027]

### 2.3 动态确认问卷

问卷目标约 5 题，只允许勾选或取消，不要求文字输入。问题由扫描结果动态生成。[D-006]

预选策略：

- 可预选：个性化指南、内置键盘选择性 Ctrl 兼容、检测到外接 Windows 键盘时的对应兼容、不会新增高权限或大型依赖的安全建议。
- 不得预选：导出 Wi‑Fi 密码、触发管理员权限、安装 Homebrew、安装轻量 AI 开发环境，以及未来新增的敏感数据类别。[D-006、D-019、D-020]

每个选项必须用结果语言说明，例如“让常用 Ctrl 复制粘贴在普通 Mac 应用中可用”，而不是只写工具名。用户仍可展开查看具体规则和例外。[D-007、D-010]

### 2.4 特权补充扫描

只有用户选择需要管理员权限的项目后，才可请求 UAC。MacWin 应把同一阶段已选择的特权读取合并为一次授权；拒绝或失败后，把受影响项目标记为 `skipped_permission`，继续非特权导出。[D-014]

Wi‑Fi 密码读取必须遵守 [`privacy-security.md`](privacy-security.md) 和 D-019。若无法读取密码，可保留用户已选择的网络名称并清楚标记降级结果。

### 2.5 导出

导出前必须显示最终模块、敏感数据提示和排除项。生成包后必须重新打开并完成结构、哈希、schema、路径和引用校验；校验失败时不得向用户显示“已完成”。[D-009、D-019、D-026、D-027]

含秘密时，完成页必须：

- 明确显示“此迁移包包含 Wi‑Fi 密码”，但不显示密码；
- 建议用用户控制的 U 盘或本地传输方式，避免公开分享；
- 告知在 Mac 导入成功后删除不再需要的副本。[D-019]

## 3. 用户自行转移文件

MacWin 不规定 USB、局域网、AirDrop 或云盘中的某一种，也不内置上传功能。文档必须提醒：含 Wi‑Fi 密码的未加密包不应放在公共链接、共享群组或不受信任的云端位置。[D-008、D-009、D-019]

## 4. macOS 目标端

### 4.1 导入与预检

导入后先验证文件，不修改系统。预检顺序：

1. 文件大小和 ZIP 基本结构；
2. 解压目标路径边界；
3. manifest schema 和支持版本；
4. 每个文件的大小、哈希和声明；
5. 规则 ID、字段类型、允许值和依赖；
6. 来源/目标平台兼容性；
7. 当前设备环境是否仍满足计划前提。[D-017、D-027]

任一结构或安全验证失败时，整个包不得进入计划生成。单个规则因目标环境不匹配而不可应用时，可以进入计划但必须明确标为跳过或需人工完成。[D-026、D-027]

### 4.2 迁移计划

计划是强制页面，不能用“快速应用”跳过。每个模块必须展示：

- 将改变的用户可识别设置；
- 扫描依据和目标值；
- 为什么建议、对 Windows 用户的收益；
- 是否安装第三方工具及其来源；
- 所需 UAC/TCC/管理员身份或其他系统交互；
- 不适用、冲突或被排除的项目；
- 预计如何验证；
- 如何按模块恢复。[D-010、D-011、D-014、D-015]

用户可取消整个计划或取消非依赖模块。取消依赖项时，所有依赖它的项目必须一并取消或重新计算，不能留下不可执行计划。

### 4.3 快照

用户确认计划后、任何目标设置变化前，必须创建一份迁移前快照。快照只收录恢复已选动作所需的目标端旧值，不收录 Wi‑Fi 密码；无法安全快照的动作必须在计划中标为不可自动恢复并再次确认，或者从 P0 自动执行中移除。[D-012、D-019]

快照创建和完整性验证失败时，不得执行任何计划动作。备份必须存放在应用包外，并包含让重装后的兼容版本发现它所需的非秘密索引。[D-012]

### 4.4 权限引导与执行

MacWin 先集中解释本计划可能出现的权限，再在系统要求时逐项触发。用户拒绝某项权限后：

- 直接依赖它的动作标记为 `skipped_permission`；
- 无依赖模块继续；
- 不重复弹出请求形成骚扰；
- 结果页说明如何稍后重试。[D-014、D-026]

动作只能调用应用中已编译或签名规则对应的平台适配器，不能执行包内命令。[D-027]

### 4.5 验证与结果

每个动作执行后必须运行独立结果检查。允许的最终状态：

- `applied_verified`：目标状态经结果检查确认；
- `skipped_user`：用户未选择或后来取消；
- `skipped_permission`：缺少权限；
- `manual_action_required`：无法安全自动化，并给出官方入口或步骤；
- `failed_recoverable`：失败且快照可恢复；
- `failed_no_change`：失败且验证确认未发生变化；
- `rolled_back_verified`：恢复后确认等于迁移前值；
- `unknown_requires_review`：无法证明成功或无变化，绝不能显示成成功。[D-013、D-026]

整个任务结果由模块状态推导：全部已验证才是“迁移完成”；存在跳过/人工操作时是“已完成，需要处理项目”；存在未知或失败时是“部分未完成”。

## 5. 恢复流程

用户可以在结果页或迁移后主页选择一个或多个模块恢复。恢复前必须显示将恢复的迁移前值和不会受影响的模块。恢复动作也要经过结果检查，失败不得删除快照。[D-012、D-026]

“全部恢复”是按依赖逆序执行所有可恢复模块，并不表示抹掉 Mac 或恢复出厂设置。Wi‑Fi 模块恢复可以删除 MacWin 新增的网络或恢复非秘密偏好，但不得在快照中保留密码。[D-012、D-019]

## 6. 删除与重装

MacWin 不注册开机启动或常驻服务。删除应用不自动删除外部快照，避免失去恢复能力；用户必须有独立的“删除备份”动作并看到影响提示。兼容版本重装后应扫描约定位置并显示可恢复快照。[D-012]

## 7. 网络行为

扫描、导出、导入、计划、系统设置、验证、报告和恢复不得因离线而失败。联网时只允许：

- 自动或手动检查 GitHub Releases/规则更新；
- 用户确认后下载已批准更新；
- 执行用户已选择的软件安装。[D-008、D-016]

无网时软件安装项变为可重试或提供用户已知的官方入口信息；其他本地模块继续。版本检查请求不得附带扫描结果、设备清单或迁移包内容。[D-008、D-013、D-016]
