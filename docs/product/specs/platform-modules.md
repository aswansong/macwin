# 平台模块规格

## 1. 通用模块合同

每个模块都必须实现同一生命周期：[D-010、D-012、D-026]

1. `detect`：只读取白名单来源，输出证据和置信度；
2. `ask`：把必要选择交给动态问卷；
3. `plan`：描述动作、原因、权限、依赖、验证和恢复；
4. `snapshot`：读取目标 Mac 当前值；
5. `apply`：只执行固定动作 ID；
6. `verify`：独立读取目标状态并与计划比较；
7. `rollback`：恢复快照并再次验证；
8. `explain`：为报告和指南提供不含秘密的用户语言。

缺少 `verify` 的动作不能返回成功；缺少安全 `snapshot/rollback` 的动作必须在计划中标记为不可自动恢复，并经负责人决定是否允许进入 P0。[D-012、D-026]

## 2. 键盘与输入

### 2.1 目标

减少 Windows 用户在复制、粘贴、剪切、撤销、全选、保存、查找等高频编辑操作中的误按，同时不破坏依赖真实 Ctrl 的上下文。[E-001、D-007]

### 2.2 设备范围

- MacBook 内置键盘：可启用“常用 Ctrl 兼容”，默认在问卷中预选并清楚展示。[D-006、D-007]
- 外接 Windows 键盘：扫描到后单独显示兼容选项，可预选；规则不得通过不稳定的单一设备名误套到所有键盘。[E-002、D-007]
- 未识别键盘：默认不应用设备专属规则，并在计划中提示人工确认。

具体设备匹配字段与优先级属于技术设计，但必须处理同型号多设备、蓝牙/有线重连和标识缺失场景。

### 2.3 选择性 Ctrl 规则

首版候选动作只覆盖负责人拍板的常用编辑意图：复制、粘贴、剪切、撤销、重做、全选、保存和查找。具体应用白名单由 D-034 确定。

硬约束：

- 不交换物理 Ctrl 与 Command 的全部含义；
- Command 原生快捷键继续可用；
- 终端、VS Code 集成终端、远程桌面、虚拟机和其他经验证依赖真实 Ctrl 的上下文必须排除；
- 不把来自 `.habitpack` 的应用 ID、按键或规则文本直接交给第三方工具执行；
- 规则关闭或模块恢复后，相关映射必须消失。[D-007、D-027]

重做在 Windows 应用中可能是 `Ctrl+Y` 或 `Ctrl+Shift+Z`，Mac 应用支持也不一致，因此最终映射必须按应用矩阵验证，不能假定一个全局组合正确。

### 2.4 输入法、Option 与 Fn

- Caps Lock 用于输入法切换可以作为安全建议，但必须检测当前目标配置并允许取消。[D-007]
- Option 与 Fn 默认不重映射；个性化指南用示例解释 Option 常用于特殊字符/替代操作，Fn 常用于功能键、系统功能和地球仪键相关操作。[D-007、D-015]
- 不迁移用户词库、个人字典、云同步内容或第三方输入法账号。[D-002]

### 2.5 第三方依赖

如果系统原生接口不能满足按应用、按设备规则，可以建议 Karabiner-Elements；安装必须遵守 D-011 和 OD-007。MacWin 必须说明该工具是否常驻、需要哪些权限、如何停用和卸载。用户拒绝后可只应用原生可支持部分，不得谎报完整兼容。

### 2.6 验证矩阵

至少验证：

- 内置键盘与一把外接 Windows 键盘；
- 常规原生文本框、浏览器、办公应用和代码编辑器；
- Terminal、VS Code 集成终端、一个远程桌面客户端和一个虚拟机上下文；
- 中英文输入法切换、Caps Lock、Command 原生快捷键；
- 键盘断开/重连、应用启动前后、睡眠唤醒后；
- 模块恢复后规则不存在。[D-007、D-023]

## 3. 鼠标与触控板

### 3.1 独立意图

鼠标滚轮方向与触控板滚动方向必须作为两个设置显示、快照、应用和验证。改变一个不得静默改变另一个。[E-003]

可表达的候选意图：

- 触控板保留自然滚动；
- 鼠标滚轮使用 Windows 式方向；
- 指针速度和主按钮只在来源证据可靠且目标接口稳定时迁移；
- 手势以教学为主，不盲目把 Windows 手势映射到不存在的 Mac 行为。[D-004]

### 3.2 第三方依赖与故障

如果分离滚动方向依赖 LinearMouse，必须在计划中显示其来源、权限、是否常驻、冲突和卸载影响。[D-011]

验证必须实际读取或观察两个设备的结果；仅写入偏好或工具返回成功不算完成。外设不存在时动作应为 `manual_action_required` 或可稍后重试，而不是成功。[E-003、D-026]

## 4. 软件与浏览器

### 4.1 扫描和匹配

只识别 D-034 白名单中的软件。每个发现项至少输出来源软件名、可验证版本、macOS 对应项、安装能力、官方入口和不匹配原因。[D-013、D-034]

不得搬运 Windows 可执行文件、破解补丁、用户数据目录、许可证密钥或登录状态。[D-002、D-013]

### 4.2 安装政策

- 用户逐项确认后，可信来源且可自动验证的应用可自动安装；
- 普通应用使用执行当时的最新稳定版，不承诺完全匹配 Windows 小版本；
- 开发运行时优先匹配主版本；
- 无网或无法可信自动化时提供官方入口并标记 `manual_action_required`；
- 安装后必须验证应用存在和版本，而不是只看下载/安装进程退出码。[D-013、D-016、D-026]

### 4.3 浏览器

浏览器只处理选择、安装和最终白名单中的安全偏好。不得读取或迁移书签、历史、密码、Cookie、登录、配置目录和扩展会话。[D-018]

指南应区分网页缩放、macOS 显示缩放和辅助功能缩放；不应擅自把 Windows 页面缩放值改成系统级设置。[E-008]

## 5. 轻量 AI 开发环境

### 5.1 触发与默认值

仅当 Windows 扫描发现相关工具，或用户主动勾选“准备轻量 AI 编程环境”时生成计划。该选项默认不勾选。[D-006、D-020]

### 5.2 候选范围

- v1.0 锁定：Visual Studio Code、Git、Node.js LTS、Python 3、Codex CLI、Claude Code；
- GitHub CLI、uv、Jupyter、Ruff、npm/pnpm、扩展和 `Projects` 工作目录属于后续候选，不进入 v1 首批扫描或迁移包。[D-020、D-034]

具体版本和扩展白名单属于后续决策；v1 首批软件按 D-034 执行。MacWin 不迁移 GitHub/编辑器 Token、SSH 私钥、环境变量秘密、聊天记录、模型凭据或项目文件。[D-002、D-008、D-034]

### 5.3 Homebrew

Homebrew 必须解释为“macOS 上常用的命令行软件包管理器，可帮助安装和更新开发工具”。普通用户流程不依赖它；开发计划需要它时单独展示将安装的位置、用途、官方来源、后续更新与卸载影响，并要求明确选择。[D-006、D-020、OD-007]

### 5.4 验证

开发工具按实际可执行版本、架构和路径验证。只检查“图标存在”不足以证明 CLI 可用；验证也不得运行用户项目或访问账号。

## 6. 个人 Wi‑Fi

### 6.1 支持范围

只列出扫描器能确定为 WPA/WPA2/WPA3 Personal 且不受管理的网络。用户必须逐项勾选网络，并另行选择是否包含密码。企业 802.1X、证书和受管网络永远排除。[D-019]

### 6.2 降级

- 普通扫描可识别允许显示的网络名称，但不得读取密码；
- 用户拒绝 UAC、系统不允许读取或密码不可用时，可导出网络名称并标记 `credential_unavailable`；
- Mac 端无法安全写入时只给出系统网络设置入口，不复制密码到剪贴板；
- 不得使用显示密码、写日志或绕过平台安全的替代方案。[D-014、D-019、OD-005]

### 6.3 验证与恢复

验证网络配置存在且安全类型符合预期；不能通过在报告中回显密码验证。是否自动连接到网络取决于环境，不作为唯一成功证据。[E-014]

恢复不得保存旧密码。可以删除由 MacWin 新增且用户选择恢复的网络记录，或恢复非秘密网络偏好；具体安全接口受 OD-005 阻塞。

## 7. 个性化指南

指南内容由实际迁移结果生成，不给所有用户一份通用长文。[D-015]

候选章节：

- 你的 Ctrl 兼容在哪些应用有效、哪些地方仍用真实 Ctrl；
- Command、Option、Fn、Caps Lock 的角色；
- 鼠标与触控板为何方向不同；
- DMG、应用程序目录、Dock、关闭窗口和退出应用；
- 浏览器页面缩放与系统显示的区别；
- 睡眠、电源、通知和专注模式；
- 已安装开发工具和 Homebrew（仅相关用户）；
- 如何重试、恢复和删除 MacWin/备份。[E-004、E-005、E-008、E-009、E-010、D-015]

对“Mac 优于 Windows”的表达必须基于场景，不做绝对断言。可以说明目标用户可能受益于 Apple 芯片设备的便携/能效、触控板与系统整合、Unix 开发环境和设备生态，但应同时说明应用兼容、游戏、企业软件或特殊外设可能仍是 Windows 更合适；具体公开文案进入发布前需核对最新事实。
