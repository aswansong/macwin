# 隐私与安全规格

## 1. 数据边界

核心功能全程本地，默认零上传、无账号、无大模型。[D-008]

允许处理的数据仅限：

- 白名单规则所需的键盘、输入、鼠标、触控板和安全偏好；
- 已知软件及开发工具的名称和主版本等匹配信息；
- 用户逐项选择的个人 Wi‑Fi 名称，以及再次明确选择时的密码；
- 为恢复已选动作所需的目标 Mac 迁移前非秘密值；
- 本地脱敏诊断信息。[D-005、D-009、D-019]

禁止处理或导出：个人文件内容、浏览器个人数据、账号凭据、Cookie、登录会话、完整注册表、完整配置目录、企业证书/网络、设备序列号（默认）和迁移无关的本地路径。[D-002、D-009、D-018、D-019]

## 2. 网络边界

断网时必须能完成扫描、导出、导入、计划、应用本地设置、验证、报告和恢复。网络只用于版本/规则检查、经确认的更新下载和经用户选择的软件安装。[D-008、D-016]

版本检查请求允许携带最低必要的应用版本、平台和架构；不得携带扫描结果、已装软件清单、SSID、设备名、用户名、路径、迁移包 ID 或稳定设备标识。最终请求字段在实现前列入安全评审。

## 3. 权限原则

- 默认普通权限；特权功能就地标注原因和影响。[D-014]
- Windows 特权扫描仅在用户选择后请求 UAC，并尽量合并为一次。[D-014]
- macOS 遵守 TCC、管理员身份、Gatekeeper 和 SIP，不尝试静默批准或绕过。[D-014]
- 拒绝权限只跳过依赖项，不能重复骚扰或伪报成功。[D-014、D-026]
- 特权辅助进程如果未来确有必要，必须有最小接口、调用者校验、固定参数 schema 和独立威胁评审；当前尚未批准其具体设计。

## 4. 威胁模型

| 威胁 | 可能后果 | 必须的控制 | 追溯 |
|---|---|---|---|
| 恶意 `.habitpack` 携带命令或路径穿越 | 目标 Mac 任意代码执行或文件覆盖 | 只认规则 ID；拒绝可执行内容、绝对路径、`..`、链接和未知文件；受限解压 | D-027 |
| ZIP 炸弹或巨大字段 | 磁盘、内存或 UI 拒绝服务 | 固定文件数、大小、路径和压缩比上限；流式验证；超限拒绝 | D-027 |
| Wi‑Fi 密码泄漏 | 未授权网络访问 | 显式选择、含秘密标记、禁止日志/报告/快照、目标端直写、临时清理、删除提醒 | D-019 |
| 更新或第三方下载被替换 | 安装恶意应用或规则 | HTTPS 不足以单独信任；应用/规则签名、来源白名单、哈希/上游签名校验 | OD-006、OD-007 |
| 权限混淆或参数注入 | 以管理员权限执行非预期操作 | 固定动作 ID、类型化参数、最小特权、拒绝字符串命令拼接 | D-014、D-027 |
| 日志记录秘密或身份信息 | 隐私外泄到 Issue 或社交平台 | 结构化事件、字段白名单、秘密检测、导出前脱敏预览 | D-015、D-019 |
| 目标环境在扫描后变化 | 应用错误目标或误报成功 | 执行前复检、动作后结果验证、未知状态不算成功 | E-014、D-026 |
| 快照本身被篡改 | 恢复失败或写入恶意值 | 快照 schema、完整性校验、固定存储位置和版本兼容性 | D-012、D-027 |
| 软链接/目录替换竞态 | 越界写入敏感位置 | 安全文件 API、拒绝链接、打开后校验、原子写入；实现时做平台专项测试 | D-027 |

## 5. Wi‑Fi 密码生命周期

```text
用户逐项勾选
  → 明确确认“包未加密”
  → 一次 UAC 读取允许的个人网络
  → 写入含秘密标记的本地迁移包
  → 用户自行传输
  → Mac 在受限内存/临时区读取
  → 直接交给受信任系统网络/钥匙串接口
  → 清理临时明文
  → 验证网络记录而不回显密码
  → 提醒删除迁移包副本
```

在任一节点，密码不得进入通用日志对象、错误插值、遥测、剪贴板、计划、报告或恢复快照。[D-019]

第一版“不加密”是明确产品取舍，不代表安全风险已解决。OD-005 未验证前，不得开始 Wi‑Fi 密码实现或对外宣传可用。

## 6. 日志与报告

正常操作不需要生成可提交日志。发生错误时可生成本地结构化诊断，默认字段只包括：应用/规则版本、平台大版本、模块/动作 ID、时间、结果代码和已知的脱敏错误类别。[D-015]

日志不得包含：

- Wi‑Fi SSID 或密码；
- 用户名、主目录或完整本地路径；
- 设备序列号、稳定硬件标识或 IP/MAC 地址；
- 迁移包原始内容、注册表/plist 值；
- Token、Cookie、账号、剪贴板内容或任意个人文件名。

若调试某问题确实需要新增字段，必须先更新数据边界和决策记录。错误页只展示本地日志位置、非敏感摘要、GitHub 链接和待确定的自媒体入口，不自动上传。[D-015、OD-001]

用户可导出的迁移报告只描述计划项、动作 ID、理由、目标结果、验证状态、权限/人工步骤和恢复方式；不得嵌入原始配置片段。[D-015、D-019]

## 7. 快照安全

快照只为恢复本次计划动作保存目标 Mac 迁移前值。它不得包含 Wi‑Fi 密码、浏览器数据或个人文件；存储在应用包外的固定用户范围位置，使用最小文件权限和完整性元数据。[D-012、D-019]

删除应用不删除快照；用户主动删除快照时必须提示之后无法自动恢复。保留周期和自动清理时间由 OD-009 决定。

## 8. 第三方与供应链

安装第三方工具前必须显示产品名、用途、官方来源、版本策略、所需权限、许可证入口、是否常驻及卸载影响。[D-011]

自动安装只允许 OD-007 最终白名单内的来源，并验证下载真实性/完整性。无法验证、许可证不允许或需要绕过 Gatekeeper/SmartScreen 时，MacWin 只能提供官方入口，不得自动安装。[D-011、D-013、D-023、OD-007]

## 9. 安全发布阻断条件

出现以下任一情况不得发布对应功能：

- 任意包内字符串可到达命令执行、路径或特权接口而没有固定 schema；
- 密码出现在日志、报告、错误、计划或快照；
- 无快照仍可开始应用可恢复设置；
- 权限拒绝被当成成功；
- 更新/规则/第三方包无法验证来源；
- 安装说明要求普通新手绕过平台安全警告；
- 未解决的高危漏洞或秘密扫描失败。[D-012、D-014、D-019、D-023、D-027]

## 10. 仍需完成的安全工作

- 确认 Wi‑Fi 凭据合法系统接口与秘密编码。[OD-005]
- 确认应用和规则更新签名、密钥轮换与撤销。[OD-006]
- 确认第三方供应链白名单和许可证流程。[OD-007]
- 为包解析、权限边界、快照和更新分别建立威胁测试与模糊测试计划。
- 决定快照保留与删除策略。
