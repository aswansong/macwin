# MacWin 产品简报

状态：已批准的产品基线；M1 第二版原型和 v1.0.0 RC 已接受，当前在 `integration/v1.0.1-final-convergence` 收口未签名 `v1.0.1-rc.2` 测试发布。未签名构建不是面向普通用户的正式 Release，也不代表所有 P0 已完成。[D-024、D-028、D-041、D-042、E-051]

## 一句话定义

MacWin 是一个面向长期 Windows 用户的本地迁移工具：它在 Windows 上读取用户明确允许的习惯与环境，生成 `.habitpack`，再在新 Mac 上先展示可解释、可回滚的迁移计划，经确认后尽可能自动应用。[D-001、D-002、D-008、D-010]

## 目标用户与真实场景

### 核心用户

- 长期使用 Windows 10/11 x64，刚购买或准备启用 Apple 芯片 Mac 的中文用户。[D-017、D-021]
- 主要做轻量工作：AI 辅助编程、文档、表格、浏览器与对话式开发工具；重视便携和续航。[E-007、E-009]
- 熟悉 `Ctrl+C/V/Z` 等 Windows 操作，但不理解 Command、Option、Fn、macOS 权限、DMG、窗口退出和触控板逻辑。[E-001、E-004、E-005、E-006]
- 希望少做手工配置，但仍要知道产品改了什么、为什么改、如何恢复。[D-010、D-012、D-015]

### 典型场景

用户仍能访问旧 Windows 电脑，在 Windows 端扫描并勾选想带走的习惯，把 `.habitpack` 通过 U 盘、局域网或用户自选方式放到新 Mac。MacWin 不负责传输这个文件，也不搬运个人文件。用户在 Mac 导入后查看计划、处理系统必需的授权，完成设置并得到验证报告和个性化指南。[D-002、D-008、D-010]

### 不是核心用户

- 需要企业批量部署、MDM、域策略或 802.1X 证书迁移的 IT 管理员。[D-002、D-019]
- 需要完整磁盘克隆、照片文档搬家、浏览器账号/密码/历史或应用数据迁移的用户。[D-002、D-018]
- Intel Mac、Windows ARM 或未列入 D-017 的平台用户；第一版只会显示不支持或实验性提示。[D-017]

## 用户要完成的任务

> “把我每天最常用的 Windows 操作和轻量工作环境带到新 Mac，不用逐项研究系统设置；在任何更改发生前让我看懂计划，出问题时能恢复。” [E-001、E-003、E-004、E-007、D-010、D-012]

## 产品目标

1. 降低高频肌肉记忆冲突，尤其是 Ctrl、内外接键盘、鼠标与触控板，同时保留必要的 Mac 原生行为。[D-004、D-007]
2. 把扫描、选择、应用、验证和恢复做成一个可解释流程，用户无需打开终端。[D-006、D-010、D-012、D-026]
3. 让核心迁移在本地离线完成，不依赖账号或大模型，也不上传扫描数据。[D-008]
4. 用白名单与声明式规则限制系统修改范围，保护密码、权限和供应链边界。[D-009、D-014、D-019、D-027]
5. 迁移完成后教会用户理解关键 Mac 差异，而不是永久依赖一个常驻兼容层。[D-004、D-015]

## MVP 边界

### P0 范围

- 支持矩阵检查与阻断。[D-017]
- Windows 白名单扫描、动态勾选问卷和必要时的一次 UAC。[D-006、D-014]
- `.habitpack` 最小化导出、结构与完整性校验。[D-009、D-019、D-027]
- Mac 导入、强制迁移计划预览和明确确认。[D-010]
- 一份迁移前快照、按模块恢复和重装后发现备份。[D-012]
- MacBook 内置键盘 Control ↔ Command、Option/Fn 说明和外接键盘保持原样。[D-041]
- 鼠标与触控板独立设置和验证。[E-003、D-005]
- 已知软件的选择、匹配、自动安装或官方入口。[D-013、D-018]
- 按需选择的轻量 AI 开发环境，并解释 Homebrew。[D-020]
- 经用户逐项选择的个人 Wi‑Fi 名称及可选密码迁移。[D-019]
- 按模块结果验证、可导出报告、个性化指南和本地脱敏错误日志。[D-015、D-026]
- 联网版本检查、手动检查和离线规则包导入。[D-008、D-016]

每一项的可执行验收标准位于 [`feature-list.json`](../execution/feature-list.json)。

### 明确非目标

- 个人文件、照片、桌面、下载目录或磁盘搬运。[D-002]
- Mac → Windows 方向。[D-002]
- 完整注册表、完整用户配置或完整系统镜像。[D-009]
- 浏览器书签、历史、密码、Cookie、登录状态和用户资料目录。[D-018]
- 企业 Wi‑Fi、证书、MDM、域、VPN 账号或企业策略。[D-002、D-019]
- 账号登录、云端服务策略和付费订阅迁移。[E-013、D-002]
- 打印机、硬件绑定音频设备和其他无法在目标机可靠匹配的外设。[E-011、E-012]
- 常驻后台助手、开机启动项或内置大模型。[D-008、D-012]
- 默认安装 Docker、Ollama 或其他重型开发栈。[D-020]

## 核心用户流程

```text
Windows 欢迎与兼容检查
        ↓
白名单扫描 ──需要特权──→ 标注原因，用户选择后一次 UAC
        ↓
约 5 个动态勾选题 + 模块/敏感项确认
        ↓
本地生成 .habitpack，并提示安全保存
        ↓  （用户自行把文件带到 Mac）
Mac 导入、格式/完整性/兼容性验证
        ↓
逐项展示迁移计划、权限、第三方工具和恢复方式
        ↓
用户确认 → 保存迁移前快照 → 尽可能自动执行
        ↓
逐模块验证；失败隔离并允许重试/跳过/恢复
        ↓
结果报告 + 个性化指南 + 简洁主页
```

详细状态和异常分支见 [`core-flow.md`](specs/core-flow.md)。

## 成功定义

Alpha 阶段不使用“体验好”作为完成标准。只有满足以下可观察条件，才可讨论进入公开新手发布准备：[D-023]

- 在至少一台真实 Windows 10 x64、一台真实 Windows 11 x64和一台分别覆盖 macOS 15/26 的 Apple 芯片 Mac 测试组合中，完成支持矩阵对应测试；若无法同时拥有两台 Mac，可在同一兼容硬件的独立系统环境中覆盖两个系统版本，并记录限制。[D-017、D-023]
- 新手测试者可在不打开终端的情况下完成扫描、导出、导入、预览、执行、查看报告和至少一个模块恢复。[D-010、D-012、D-023]
- 键盘兼容不会改变终端、VS Code 终端、远程桌面和虚拟机中的真实 Ctrl 测试用例。[D-007]
- 鼠标与触控板滚动方向可独立验证，外设重新连接后结果符合计划或被明确报告为需重试。[E-003、D-026]
- Wi‑Fi 密码不出现在 UI、计划预览、导出报告、日志、错误或回滚快照的自动化秘密扫描与人工抽检中。[D-019]
- 任一非依赖模块失败时，其他已确认模块仍能完成并独立报告状态。[D-026]
- 删除并重装 MacWin 后，可以重新发现迁移前备份并执行恢复演练。[D-012]
- 面向普通新手的安装包具备 D-023 要求的签名、公证和可信分发；在此之前只能称为知情 Alpha。[D-023]

## 关键假设与反方检查

| 假设 | 为什么危险 | 如何证伪 | 当前状态 |
|---|---|---|---|
| 内置键盘 Control ↔ Command 能覆盖大多数新手痛点 | 设备标识或系统映射变化会导致误改或恢复失败 | 在 MacBook 内置键盘上验证四方向、幂等、重连和精确恢复；外接键盘前后值不变 | 待真实设备验证；D-041 |
| 用户仍能同时使用旧 Windows 和新 Mac | 旧机可能已出售、损坏或受企业限制 | Alpha 招募时记录双机可用性；没有旧机时明确无法扫描 | 待验证 |
| 不加密 `.habitpack` 仍可安全承载 Wi‑Fi 密码 | 文件可能被误传、云同步或遗留在 U 盘 | 威胁建模、秘密扫描、删除提醒测试；若风险不可接受，重新拍板 | 高风险已知取舍；D-009、D-019 |
| 合法平台接口允许可靠迁移 Wi‑Fi 凭据 | 系统版本、权限或 API 可能阻止自动读取/写入 | 对 Win10/11 与 macOS 15/26 做最小技术样例，验证无明文泄漏 | 未解决；OD-005 |
| 第三方工具能长期稳定且可信地自动安装 | 上游更新、许可证、签名或系统兼容性会变化 | 固定来源并验证签名/哈希，做卸载与升级测试 | 未解决；OD-007 |
| “约 5 题 + 默认预选”足以形成正确计划 | 过度默认可能造成未经理解的修改 | 可用性测试中要求用户复述敏感项与预期结果 | 待验证；D-006 |
| Tauri 2 架构能覆盖双平台系统能力 | 系统操作仍需大量平台原生桥接，复用率可能低 | 原型后单独做无 UI 技术预研 | 临时决定；D-022 |
| GitHub Releases 适合普通中文新手 | 下载、SmartScreen/Gatekeeper 和网络可达性可能阻断 | 记录首次安装完成率和每个阻断点 | 待验证；D-003、D-023 |

## 主要失败风险

1. **安全风险**：未加密包中的 Wi‑Fi 密码、ZIP 路径穿越、规则注入、日志泄密和更新供应链攻击。[D-019、D-027、OD-006]
2. **平台脆弱性**：依赖未公开或随系统版本变化的设置接口，导致 macOS 更新后失效。[OD-005、OD-007]
3. **错误兼容**：全局快捷键规则破坏专业应用、终端或远程环境。[E-001、E-002、D-007]
4. **假成功**：命令返回成功但用户可见效果没有发生，如外设、权限或网络状态变化。[E-012、E-014、D-026]
5. **范围膨胀**：从习惯迁移滑向文件、账号、浏览器数据和企业管理。[D-002、D-018]
6. **信任风险**：未签名系统工具、含密码文件或第三方安装让新手难以判断安全性。[D-011、D-019、D-023]

## 产品原则

- 先看计划，再改系统。[D-010]
- 默认本地与最小数据，而不是默认收集。[D-008、D-009]
- 只执行已知规则，不执行包内命令。[D-027]
- 需要权限时说明“为什么”，拒绝后安全降级。[D-014]
- 每个动作都能解释、验证和恢复。[D-012、D-015、D-026]
- 自动化减少重复劳动，但不替用户绕过安全确认。[D-010、D-014]
- 迁移高频习惯，同时教会用户理解 Mac。[D-004、D-015]
