# MacWin v1.0.1 公开版（未签名）

MacWin 帮助 Windows 10/11 x64 用户把经过选择的习惯与环境带到 Apple 芯片 Mac。此版本源码和安装包公开下载，但 **没有 Windows Authenticode 签名、Apple Developer ID 签名或公证**，不能称为可信签名版本。

## 下载与支持范围

- [GitHub Releases 最新版](https://github.com/aswansong/macwin/releases/latest)
- Windows 10/11 x64：唯一的 NSIS 安装器
- Apple 芯片 macOS 15/26：唯一的 DMG
- 下载后先用同一 Release 中的 `SHA256SUMS.txt` 校验文件，再查看 `BUILD-INFO.json` 的源码提交和 `README-FIRST.md` 的安装说明。

## 重要安全提示

- Windows SmartScreen 可能显示未知发布者或阻止安装；macOS Gatekeeper 可能阻止打开。
- 如果系统阻止，请停止并保留系统提示，等待可信签名版本或联系维护者；本项目不提供关闭、绕过或削弱 SmartScreen、Gatekeeper、SIP、TCC 的命令。
- 不要从其他网站下载，不要上传 `.habitpack`、Wi‑Fi 密码、日志原件、用户名、设备序列号或本地路径到 Issue。
- 本版本不启用未签名自动更新，也不会通过 Release 生成 `latest.json`。

## Windows → Mac 三步

1. 在 Windows 上检测并选择要迁移的习惯，生成 `.habitpack`；用 U 盘或你信任的本地方式带到 Mac。
2. 在 Apple 芯片 Mac 上导入迁移包，先阅读迁移计划；确认前不会修改系统。
3. 确认后查看报告和指南；若需要恢复，在结果页选择单项或全部恢复。恢复针对迁移前快照，不是恢复出厂设置。

## 隐私与功能边界

- 核心流程本地运行、无账号、无大模型，不上传扫描数据。
- 只处理白名单习惯与环境；不搬个人文件、浏览器历史/密码/Cookie、账号、Token、SSH 私钥或项目代码。
- Wi‑Fi 密码真实迁移、可信软件自动安装、第三方工具静默安装、签名更新和完整四设备矩阵不属于本版本已完成能力。
- MacBook 内置键盘 Control ↔ Command 使用 macOS 原生映射；外接键盘、Option 与 Fn 不重映射。应用前保存一份迁移前快照，恢复按模块进行。

## 问题反馈

请使用 [GitHub Issues](https://github.com/aswansong/macwin/issues)，只提交脱敏的应用版本、短错误码和复现步骤。不要附迁移包、密码或未脱敏日志。
