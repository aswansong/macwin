# MacWin v1.0.1-rc.2（未签名测试版）

这是 MacWin 的 Windows → Mac 未签名候选版本，仅供仓库负责人和明确知情的 Alpha 测试者使用。它不是面向普通新手的正式版本，也没有 Windows 代码签名、Apple Developer ID 签名、公证或 stapling。

## 本次候选包含

- 原生 Tauri App 版本对齐为 `1.0.1-rc.2`（Cargo 包基础版本为 `1.0.1`）。
- MacBook 内置键盘使用 macOS 原生逐设备映射，把物理 Control 与 Command 同时互换；外接键盘、Option 与 Fn 保持不变。
- Mac 键位模块会读取并显示可能的第三方冲突，但不会安装、配置或写入 Karabiner 等第三方工具。
- v6 视觉整合后的 Windows W1 → W3 与 Mac 导入、计划、执行、报告、指南、恢复流程；保留原生标题栏，不绘制网页仿系统按钮。
- MacWin 自己的 `.habitpack` 规则、schema 和快照格式仍保持 `1.0.0`，并兼容读取旧快照。
- Windows x64 NSIS 安装器与 Apple Silicon macOS DMG；两个包均由同一次 GitHub Actions 提交构建，并附 `SHA256SUMS.txt`。

## 明确没有包含

- 没有个人文件、浏览器书签、历史、密码、Cookie、登录状态、Token、SSH 私钥或项目代码迁移。
- 没有真实 Wi‑Fi 密码迁移；不要把密码或完整迁移包上传到 Issue。
- 软件和第三方工具只提供固定白名单与官方入口；没有静默安装、Homebrew 自动安装或来源猜测。
- 没有正式自动更新签名链；不要把占位公钥当作生产更新信任根。

## 安全提示

- Windows 包未签名，可能触发 SmartScreen；macOS DMG 不是 Developer ID/公证包，可能触发 Gatekeeper。
- 不要通过关闭 SmartScreen、Gatekeeper、SIP、TCC 或其他系统安全功能来运行测试包。若系统阻止，请停止并记录系统提示，或等待正式签名版本。
- 只在你能恢复或重装的测试设备上使用。应用设置前会生成一份迁移前快照；恢复只针对 MacWin 实际应用的模块。
- 包内没有执行脚本或任意命令。需要系统权限的步骤会逐项提示，拒绝后会降级或跳过。

## 测试建议

请按 [真实设备验收手册](../execution/real-device-acceptance.md) 运行 Windows 10/11 x64 与 Apple Silicon macOS 15/26 的主流程、键位互换/精确恢复、拒绝权限、断网软件待处理、单模块失败和按模块恢复。反馈时只提供脱敏状态、应用版本和短设备 ID；公开问题请使用仓库的 GitHub Issues，不要附迁移包、密码、用户名、序列号或绝对路径。

## 与 v1.0.1-rc.1 的主要变化

- Windows 与 Mac 分支按 release 基线合流，保留两端真实适配与严格包解析修复。
- Mac 键盘兼容从第三方选择性规则改为 macOS 原生内置键盘 Control ↔ Command 互换；快照记录精确旧值并支持旧快照读取。
- 修正 Mac/Windows 网页层仿系统标题栏和品牌位置，并统一蓝色 MW 应用图标资源。
- CI 改为 rc.2 版本，构建真实 Windows x64 NSIS 与 Apple Silicon DMG，并在发布前校验同一提交、文件数量和 SHA-256。

正式 v1.0.1 仍需 Windows 代码签名、Apple Developer ID 签名与公证、真实设备矩阵、更新签名凭据和负责人最终确认。本候选不会创建或替代正式 `v1.0.1` Release。
