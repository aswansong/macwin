# MacWin v1.0.0-rc.1 未签名测试版

这是给仓库负责人和明确知情测试者使用的 Windows → Mac 迁移候选版本，不是面向普通新手的正式版。

## 重要提示

- Windows 安装器尚未进行 Authenticode 代码签名，SmartScreen 可能显示未知发布者。
- macOS App 只有免费的 ad-hoc 本地完整性签名，没有 Apple Developer ID 或公证，Gatekeeper 会要求手动确认。
- 只从本仓库的 GitHub Pre-release 下载，并先核对 `SHA256SUMS.txt`。
- 不要通过关闭 SmartScreen、Gatekeeper、SIP 或其他系统安全功能来安装。
- 当前不支持 Wi-Fi 密码迁移或第三方软件自动安装；软件项只提供官方入口。
- 只迁移习惯与环境，不迁移个人文件、浏览器数据、账号、Token、SSH 密钥或项目代码。

## 测试顺序

1. 在 Windows 10/11 x64 安装 MacWin，检测并导出 `.habitpack`。
2. 用 U 盘、局域网或你信任的传输方式把 `.habitpack` 送到 Mac。
3. 在 Apple 芯片 macOS 15/26 安装 MacWin，导入迁移包。
4. 先阅读并确认迁移计划，再执行设置。
5. 检查报告、个性化指南、按模块恢复和全部恢复。
6. 按 [`real-device-acceptance.md`](../execution/real-device-acceptance.md) 记录脱敏结果。

## 系统警告

这是未签名构建，因此只适合你自己的测试设备。Windows 上只在确认文件来自本仓库且哈希一致时使用 SmartScreen 的手动继续入口。macOS 上先尝试打开应用，然后在“系统设置 → 隐私与安全”中使用 Apple 提供的“仍要打开”入口。

发现问题请使用 [GitHub Issues](https://github.com/aswansong/macwin/issues)，不要上传 `.habitpack`、密码、完整日志或其他私人信息。
