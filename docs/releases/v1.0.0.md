# MacWin v1.0.0

状态：发布说明草稿；当前没有 GitHub Release，未签名构建不得作为正式版本分发。[D-032、E-021]

MacWin 帮助 Windows 10/11 x64 用户把日常习惯和轻量环境带到 Apple 芯片 Mac。它只处理经过选择的习惯与环境，不搬运个人文件、浏览器数据、账号或项目内容。

## 发布内容

- Windows x64 安装包与 Apple 芯片 macOS DMG。
- Tauri updater 所需的签名产物、双平台 SHA-256、Cargo/npm SBOM 和 `latest.json`。
- 首次使用、计划确认、迁移后报告、个性化指南、按模块恢复和迁移前快照。

## 当前支持

- 选择性 Ctrl 兼容：普通应用的固定 Ctrl 快捷键映射到对应 Command；终端、远程桌面、虚拟机和 VS Code 集成终端保留真实 Ctrl。
- Finder 文件扩展名、键盘重复速度，以及鼠标/触控板方向的安全原生降级路径。
- Chrome、Edge、Firefox、Microsoft 365、WPS Office、Visual Studio Code、Git、Node.js、Python、Codex CLI 和 Claude Code 的安装选择与官方入口。

## 明确限制

- 软件项目在当前发布门关闭前只提供官方入口，不静默安装或绕过 Gatekeeper/SmartScreen。
- Wi‑Fi 密码、浏览器书签/历史/密码/Cookie、账号、Token、SSH 私钥、环境变量秘密、项目代码和个人文件不会迁移。
- 不同设备、权限弹窗、真实安装/卸载和升级行为必须以对应 Windows 10/11、macOS 15/26 验收记录为准。

## 安全与隐私

MacWin 默认全程本地运行、无账号、不常驻、不自启动。应用设置前必须确认迁移计划；迁移前快照保留到用户主动删除。更新只接受经过签名验证且由用户确认的安装。
